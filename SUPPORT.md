# Support

## Getting help

Start with the README, the [specification](SPECIFICATION.md), the
[authoring guide](docs/syntax.md), and the examples in `examples/`.

For questions, usage help, or discussion, open a GitHub issue using the
question label and include the version or commit, the relevant contract snippet,
the command you ran, and the expected outcome. Keep credentials and other
sensitive information out of public issues.

## What maintainers can help with

Maintainers can clarify the specification, schemas, CLI behavior, and expected
contribution process. They cannot provide production operational support or
guarantee compatibility with third-party tools.

For a reproducible defect, use the bug-report template. For a new core resource
or material semantic change, open a public proposal as described in
[CONTRIBUTING.md](CONTRIBUTING.md).
